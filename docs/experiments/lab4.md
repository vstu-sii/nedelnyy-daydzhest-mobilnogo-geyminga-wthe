# Записка: что дал A/B и какое решение приняли

**Роль:** AI Engineer
**Спринт:** Lab4 — Iteration
**Дата:** 2026-11-13

## 1. Что сравнивали

Сравнили два варианта промптов:
- **v1 (Baseline):** короткие промпты из лабы 3. Без жестких ограничений.
- **v2 (Итерация):** промпты с жесткими правилами (только русский язык, строго JSON без markdown, запрет на выдумывание фактов).

Прогон на 5 играх из синтетического датасета.

## 2. Что показали цифры

| game_id | v1_tokens | v2_tokens | v1_latency | v2_latency | Исправление категории |
|---|---|---|---|---|---|
| nr_002 | 5073 | 1237 | 31.64 с | 5.04 с | green -> green |
| tt_001 | 5348 | 898 | 29.70 с | 10.21 с | red -> **green** (исправлено) |
| so_003 | 1084 | 3153 | 5.53 с | 22.69 с | green -> green |
| synth_004 | 4101 | 2791 | 56.16 с | 28.47 с | green -> yellow |
| synth_005 | 862 | 1260 | 4.78 с | 8.73 с | red -> **yellow** (исправлено) |

**Средние значения:**
- **Токены (v1 vs v2):** 3293 vs 1867 (сокращение на **43%**).
- **Latency (v1 vs v2):** 25.56 с vs 15.03 с (ускорение на **41%**).

## 3. Вывод и решение

**Решение: принимаем v2.**

Почему:
1. **Экономия.** В среднем v2 тратит почти в 2 раза меньше токенов. Это напрямую снижает стоимость API.
2. **Скорость.** v2 работает на 10 секунд быстрее в среднем. Это критично для генерации дайджеста с десятками игр.
3. **Качество.** v2 исправил критические ошибки классификации (`tt_001` и `synth_005`), которые были в v1.

**Единственный минус:** на одной игре (`so_003`) v2 потратил больше токенов и времени (3153 токена и 22 секунды против 1084 и 5.5). Это особенность бесплатного роутера `openrouter/free` (он мог направить запрос на медленную модель). На стабильном платном API (Gemini) этой проблемы не будет.

**Изменения без прироста откатываются:** мы не вносили изменений, которые ухудшили результат. Переход на v2 дал прирост по всем фронтам.
