## 1. Глоссарий команды

Дайджест - еженедельная подборка карточек игр в формате доски, автоматически сгенерированная на основе рыночных данных.
Карточка проекта - единица дайджеста: квадрат с тремя блоками (шапка игры, описание, динамика метрик) по одной игре.
Категория (цвет карточки) - метка, присваиваемая игре: зелёный, жёлтый, красный, бирюзовый (см. ниже).
Зелёная категория - игра с устойчивым долгосрочным успехом.
Жёлтая категория - успешный проект, требующий наблюдения (тренд не устоялся).
Красная категория - проект, показавший успех ранее, но потерявший позиции.
Бирюзовая категория - категория "смотрите что нашли": проект, похожий по жанру/механикам на продукт студии, необязательно топовый по метрикам.
Отбор в дайджест - правило, по которому игра попадает в выпуск (например, вхождение в топ-3 чартов + дополнительные критерии).
Gross - суммарная выручка игры за период.
Installs (установки) - количество загрузок игры за период.
Динамика метрик - изменение gross/installs во времени (рост/падение/стагнация), визуализируется графиком на карточке.
Гео-разбивка - распределение установок игры по странам.
Эталонный дайджест - дайджест, собранный вручную аналитиком, используется как образец для сверки качества автоматической генерации.
Совпадение с эталоном (% quality match) - guardrail-метрика: насколько авто-сгенерированный дайджест совпадает с эталонным по ключевым критериям.
North Star - главная метрика продукта: % дайджестов, опубликованных без ручной правки аналитика.
Guardrail - ограничение, внутри которого должна достигаться North Star (например, предел задержки или цена запроса).
Задержка генерации - время от запуска сборки дайджеста до готового черновика.
Источник данных - внешняя платформа/канал, откуда собираются сырые данные.
Черновик дайджеста - версия дайджеста до финальной проверки аналитиком, в частности для категорий, требующих экспертного подтверждения.
Weekly-дайджест (еженедельный) - регулярный выпуск раз в неделю (пятница/понедельник) с играми, попавшими в отбор за неделю: топ-3 чартов + доп. критерии.
Monthly-дайджест (ежемесячная оценка топов) - выпуск в конце месяца: отбор проектов из топов, подъём истории за период и пересборка оценки с трендом по неделям.
Тип дайджеста - параметр запуска пайплайна (weekly / monthly), определяет набор карточек, глубину истории и логику динамики; отображается аналитику в шапке доски.
MVP-скоуп - минимальный набор возможностей, достаточный, чтобы закрыть UC1 + UC2 в обоих режимах (weekly / monthly) и измерить North Star с guardrails.
Не-скоуп - явный список того, что осознанно не делается в MVP, чтобы скоуп не полз (фиксируется вместе с MVP-скоупом).
Веха - контрольная точка роадмапа с фиксированным сроком, результатом и критерием прохождения.
Demo Day - финальная демонстрация продукта; к ней привязаны все вехи роадмапа.
Контрольная точка по риску - момент в роадмапе, где фиксируется решение о сужении/расширении скоупа при срабатывании риска (например, урезание monthly до месячного среза без тренда).
Closed beta - этап пилотной эксплуатации на реальных данных у ограниченного числа пользователей (в MVP - один пилотный аналитик).
Пилотный аналитик - продуктовый аналитик, который первым использует продукт на реальных выпусках и даёт обратную связь.
Baseline - зафиксированное стартовое значение метрики (quality match, задержка, цена) до начала улучшений, отдельно для weekly и monthly.
Пайплайн сборки - последовательность шагов от сырых данных до черновика дайджеста, запускается по расписанию без ручного вмешательства.
Ветка пайплайна (weekly / monthly) - разветвление логики сборки в зависимости от типа дайджеста: отбор, глубина динамики, работа с историей.
LLM-генерация описания - автоматическое формирование краткого описания идеи игры на основе стор-материалов и промо-материалов.
