## 1. Глоссарий команды

Дайджест - еженедельная подборка карточек игр в формате доски, автоматически сгенерированная на основе рыночных данных.
Карточка проекта - единица дайджеста: квадрат с тремя блоками (шапка игры, описание, динамика метрик) по одной игре.
Категория (цвет карточки) - метка, присваиваемая игре: зелёный, жёлтый, красный, бирюзовый (см. ниже).
Зелёная категория - игра с устойчивым долгосрочным успехом.
Жёлтая категория - успешный проект, требующий наблюдения (тренд не устоялся).
Красная категория - проект, показавший успех ранее, но потерявший позиции.
Бирюзовая категория - категория "смотрите что нашли": проект, похожий по жанру/механикам на продукт студии, необязательно топовый по метрикам.
Отбор в дайджест - правило, по которому игра попадает в выпуск (например, вхождение в топ-3 чартов + дополнительные критерии).
Gross - суммарная выручка игры за период.
Installs (установки) - количество загрузок игры за период.
Динамика метрик - изменение gross/installs во времени (рост/падение/стагнация), визуализируется графиком на карточке.
Гео-разбивка - распределение установок игры по странам.
Эталонный дайджест - дайджест, собранный вручную аналитиком, используется как образец для сверки качества автоматической генерации.
Совпадение с эталоном (% quality match) - guardrail-метрика: насколько авто-сгенерированный дайджест совпадает с эталонным по ключевым критериям.
North Star - главная метрика продукта: % дайджестов, опубликованных без ручной правки аналитика.
Guardrail - ограничение, внутри которого должна достигаться North Star (например, предел задержки или цена запроса).
Задержка генерации - время от запуска сборки дайджеста до готового черновика.
Источник данных - внешняя платформа/канал, откуда собираются сырые данные (SensorTower, AppMagic, Data.ai, Reddit, Discord, новостные каналы).
Черновик дайджеста - версия дайджеста до финальной проверки аналитиком, в частности для категорий, требующих экспертного подтверждения (см. гипотезу 4).
