Черновик DoD команды
DoD (Definition of Done) — договорённость внутри команды, когда артефакт считается готовым. Здесь — черновик для артефактов лабы 2. Каждый критерий проверяемый: да/нет, число или ссылка.
Артефакт 1: success-criteria.md

 Критерий | Тип проверки | Как проверяем |
| 1 | Файл лежит по пути `docs/quality/success-criteria.md` | да/нет | Открыть репозиторий по ссылке |
| 2 | У каждой метрики есть целевое число | да/нет | Просмотр таблицы |
| 3 | У каждой метрики есть способ подсчёта | да/нет | Просмотр таблицы |
| 4 | Есть связь с болями из PRD | да/нет | Раздел «Связь с болями» |
| 5 | Указано, что автоматизируется в лабе 3 | да/нет | Раздел «Что автоматизируется» |
| 6 | Минимум 5 метрик качества + 3 инженерных | число | Подсчёт строк в таблицах |
Артефакт 2: golden-dataset-plan.md

Критерий | Тип проверки | Как проверяем |
| 1 | Файл лежит по пути `docs/quality/golden-dataset-plan.md` | да/нет | Открыть репозиторий |
| 2 | Описан источник примеров (минимум 3 источника) | число | Подсчёт в разделе «Откуда беру примеры» |
| 3 | Указана версия датасета и дата фиксации | да/нет | Раздел «Происхождение и версия» |
| 4 | Указан владелец датасета | да/нет | Раздел «Формат записи и владелец» |
| 5 | Есть пример записи в JSON | да/нет | Блок с кодом |
| 6 | Первые 10 примеров оформлены таблицей | число | Подсчёт строк (10 шт.) |

Артефакт 3: Pull Request

 Критерий | Тип проверки | Как проверяем |

| 1 | PR создан из ветки студента в main | да/нет | Ссылка на PR |
| 2 | В PR не меньше 2 изменённых файлов | число | Вкладка Files changed |
| 3 | У всех коммитов осмысленные сообщения | да/нет | Вкладка Commits |
| 4 | PR не смержен без ревью | да/нет | Статус PR |
