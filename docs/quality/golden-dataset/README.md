# Golden Dataset v1

## Что это

Набор эталонных пар «вход → правильный ответ» для проверки агента недельного дайджеста мобильного гейминга.

Собран из use cases: берём реальные ситуации пользователя и показываем, какой дайджест считается правильным.

## Формат

JSONL — по одному JSON-объекту на строку. Читается большинством инструментов evals.

Поля записи:
- `id` — уникальный номер кейса
- `use_case` — какая ситуация проверяется
- `input` — что подаём на вход (статьи недели)
- `expected_output` — эталонный дайджест
- `expected_sources` — источники, на которые агент должен опираться
- `notes` — комментарий
