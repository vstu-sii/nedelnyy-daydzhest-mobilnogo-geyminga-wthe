## Что такое спайк

Спайк — короткий одноразовый эксперимент на один вопрос: тридцать строк, ответ, код выброшен. Самое рискованное место пайплайна проверяется до того, как вокруг него построена система.

Мы не строим полный пайплайн. Мы проверяем **два самых рискованных допущения** из дизайна AI-пайплайна. Всё остальное можно проверить потом.

## Спайк 1: качество суммаризации нарратива

**Вопрос:** даёт ли Gemini 3.1 Pro описание игры, совпадающее с ручным описанием аналитика на ≥80%?

**Метод:**
- 5 игр из топ-10 мобильного гейминга за июнь 2026.
- Вход в промпт: название, разработчик, описание из стора, жанр, промо-материалы.
- Эталон: ручное описание от аналитика по тем же данным (написано до прогона).
- Оценка: ручное сравнение по критериям: корректность нарратива, отсутствие выдуманных деталей, соответствие жанру, отсутствие путаницы с похожими играми.

**Что замеряем:**
- % совпадения с эталоном (0–100%).
- Наличие галлюцинаций (выдуманные фичи, перепутанные разработчики).
- Стоимость одной карточки (токены × цена).
- Latency на один прогон.

**Результат:**

|---|---|---|---|---|
| Игра 1 | заполняется после прогона | — | — | — |
| Игра 2 | | | | |
| Игра 3 | | | | |
| Игра 4 | | | | |
| Игра 5 | | | | |

**Вывод:** заполняется после прогона.

**Что делаем, если Д1 не подтвердится:**
- Если совпадение <60% — переходим на GigaChat Pro (русский) или Claude Sonnet 5.
- Если 60–80% — дорабатываем промпт (few-shot примеры, chain-of-thought).
- Если ≥80% — допущение подтверждено, идём дальше.

## Спайк 2: классификация без ложных «зелёных»

**Вопрос:** не даёт ли Cotype-Nano ложную метку «зелёный» на играх со случайным всплеском метрик?

**Метод:**
- 10 примеров игр: 5 с реальным ростом (подтверждён историей за 4 недели), 5 со случайным всплеском (рост за 1 день, но стабильный нисходящий тренд).
- Вход в промпт: метрики gross/installs за 4 недели, geo-разбивка, описание нарратива.
- Эталон: категория, которую аналитик поставил вручную.
- Оценка: точность на каждом классе, отдельно — ложные «зелёные» (false positive).

**Что замеряем:**
- Точность (accuracy) на 10 примерах.
- False positive rate по классу «зелёный».
- Стоимость классификации.
- Latency.

**Результат:**

| Пример | Реальная категория | Предсказанная | Ложный «зелёный»? |
|---|---|---|---|
| Реальный рост 1 | зелёный | заполняется | — |
| Реальный рост 2 | зелёный | | |
| ... | | | |
| Случайный всплеск 1 | жёлтый | | |
| Случайный всплеск 2 | жёлтый | | |
| ... | | | |

**Вывод:** заполняется после прогона.

**Что делаем, если Д2 не подтвердится:**
- Если ложных «зелёных» больше 20% — переходим на Gemini 3.5 Flash Lite или усиливаем промпт историческим контекстом.
- Если точность <70% — добавляем few-shot примеры переходов между категориями.
- Если точность ≥80% и ложных «зелёных» <10% — допущение подтверждено.
