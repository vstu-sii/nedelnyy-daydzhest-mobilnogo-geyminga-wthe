## 1. Проблемы интервью

1. Ручной сбор данных (2–6 часов/неделю) - подтверждено. Аналитики в mobile F2P без единого автоматизированного пайплайна действительно тратят это время на агрегацию данных из SensorTower/AppMagic/Data.ai и соцсетей вручную.

2. Дайджест используется в реальных решениях - подтверждено. Дайджест выступает не формальностью, а рабочим инструментом: на него ссылаются при обсуждении фич и приоритизации бэклога.

3. Готовность доверять авто-описанию без перепроверки - частично подтверждено, с оговоркой. Доверие возможно только при устойчиво высоком совпадении с ручной оценкой на тестовых кейсах; при разовых ошибках аналитики возвращаются к перепроверке - то есть гипотеза верна не как факт "доверяют всегда", а как условие "доверяют, если качество стабильно высокое".

4. Автоматическое присвоение категории по метрикам - не подтверждено полностью. Присвоение категории (особенно "скатился"/"долгосрочный успех") требует экспертного контекста, который сложно свести к чистой формуле по gross/installs - метрики дают только часть картины, финальное решение остаётся экспертным.
