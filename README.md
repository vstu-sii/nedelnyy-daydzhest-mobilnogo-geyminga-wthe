Недельный дайджест мобильного гейминга — проект курса «Системы искусственного интеллекта»

## Запуск эксперимента (Lab 3)

Для воспроизведения прогона baseline-модели:
1. Установите зависимости: `pip install openai tenacity pandas`
2. Задайте ключ: `export OPENROUTER_API_KEY="sk-or-v1-..."`
3. Запустите: `python run_experiment.py`
